# Build without installing Gradle

You do NOT need the `gradle` command installed globally.

The project includes `build.ps1`, which downloads Gradle 9.8.0 into the
project directory the first time you build.

You still need Java 21.

## PowerShell

From the project root:

```powershell
.\build.ps1
```

The first run downloads Gradle. Later runs reuse the local copy.

The plugin jar will be:

```text
build\libs\civ-microscope-1.0.0.jar
```

Then put that jar in the Paper server's:

```text
plugins\
```

directory.

## If PowerShell blocks the script

Run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

and then:

```powershell
.\build.ps1
```

This changes the policy only for the current PowerShell process.

## Why this exists

Gradle's official recommendation for existing projects is normally the Gradle
Wrapper (`gradlew.bat`), which downloads and uses the project's declared
Gradle version. The wrapper itself is normally generated by a machine that
already has Gradle installed. This project instead uses a small PowerShell
bootstrap so a first-time Windows user can build it without globally
installing Gradle.
